# Словарь

Веб-приложение для чтения словарей: быстрый поиск без диакритики, исправление опечаток, формы слов («etes» → «être»), поиск по тексту статей и группы словарей. Работает целиком в браузере и устанавливается как приложение.

**Открыть:** https://twwilightpretender.github.io/slovar/  
**Как пользоваться:** https://twwilightpretender.github.io/slovar/help.html

## Главное

- **Словарей на сайте нет.** Страница хранит только код. Словари вы подключаете сами: папкой на компьютере или ссылкой на облачную папку (Яндекс.Диск, Google Диск). При подключении из облака файлы один раз скачиваются в память вашего браузера, дальше всё работает локально и без интернета.
- **Ничего не отправляется на сервер.** Поиск и чтение статей идут на вашем устройстве. Нет учётных записей, аналитики и серверной части.
- **Форматы:** MDict (`.mdx` + `.mdd`, в том числе с шифрованием индекса), DSL (`.dsl`, `.dsl.dz`, ресурсы в `.dsl.files.zip`), StarDict (`.ifo`/`.idx`/`.dict`, `.syn`), Slob, Babylon GLS. BGL пока не читается (переведите в DSL).
- **Быстро:** индекс строится один раз и кэшируется; запуск с 5–6 млн заголовков занимает около 2 секунд.

## Браузеры

| Браузер | Папка на компьютере | Облако |
|---|---|---|
| Chrome, Edge (компьютер) | да, папка запоминается | да |
| Chrome на Android | выбор папки недоступен | да (должно работать, не проверено) |
| iPhone (Safari и любой браузер на iOS) | выбор папки недоступен | да, через запасную запись в воркере (проверено имитацией, на устройстве не проверено) |
| Firefox, Safari на компьютере | перетаскивание папки на страницу | Safari да, Firefox вероятно |

## Разработка

Нужен Node.js 20+.

```bash
npm install
npm run dev        # http://127.0.0.1:8742
npm run build      # сборка в dist/
npm run typecheck
```

Сборка и публикация на GitHub Pages идут автоматически: каждый `git push` в `main` запускает `.github/workflows/deploy.yml`. Ссылки на облачные папки со словарями в репозиторий не кладём: по ним можно скачать словари.

### Устройство

```
src/
  main.ts            интерфейс, поиск, облако, настройки
  worker/            движок поиска в Web Worker (индекс, кэш в IndexedDB)
  readers/           читалки форматов (mdx, dsl, stardict, slob, gls)
  storage/           выбор папки и облако (Яндекс.Диск, Google Диск)
  ui/                карточки статей (Shadow DOM), группы, ресурсы статей
  core/              нормализация ключей, протокол воркера
public/              значки, манифест и service worker (PWA), страница справки
```

Облако: публичная ссылка → список файлов через API → скачивание в OPFS (с докачкой и повторами) → чтение как обычная папка. Для Google Диска нужен ключ API, указанный в `src/storage/cloud.ts` или введённый пользователем в окне подключения.

Если меняется нормализация ключей (`src/core/normalize.ts`), увеличьте `MERGED_VERSION` в `src/worker/engine.worker.ts`, чтобы пересобрался общий индекс. Если меняется формат кэша читалок, увеличьте `VERSION` там же.
